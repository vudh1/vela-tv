# Vela bundled wallpaper credits

- **Alpine, Dusk, Dawn, Moonlight:** original Vela SVG backgrounds carried forward from Vela 1.8 (stored as the landscape SVG assets).
- **Misty Lake, Blue Coast, Amber Dunes, Lavender Bay:** images generated specifically for Vela 1.9 on October 24, 2026, then compressed to bundled offline WebP variants and previews.

These are the wallpapers found in the current Vela repository. No CleanFrame photographs are included in the tracked wallpaper folders. [CleanFrame](https://github.com/nthnclrk/CleanFrame) is a design/reference project; its own code (MIT), images and font licenses remain independent.
